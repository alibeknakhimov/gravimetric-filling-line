# Промышленная линия розлива по весу: модернизация прошивки

> Brownfield-модернизация 5-колонной линии розлива жидкой лекарственной формы.
> Убран блокирующий MCU с 5× HX711, вместо него: промышленные индикаторы по
> Modbus RTU. Прошивка контроллера шаговиков переписана: отдельный конечный
> автомат Modbus и новый алгоритм розлива со слежением сопла за уровнем.
>
> **Результат: производительность 480 → 650 флаконов/час (+35 %), снижен брак
> по переливу, калибровка перенесена из внутреннего меню платы на штатные
> кнопки на каждом индикаторе.**

**Роль:** единственный embedded-инженер (прошивка, шилд RS-485↔UART, полевая
интеграция, обучение оператора).
**Сроки:** 3 недели на тестовом стенде · 2 дня интеграция на объекте ·
3 месяца полевых итераций в продакшене.
**Отрасль:** промышленный розлив жидкости, фармацевтическое производство.
**MCU:** STM32F407VG (F4 Discovery), bare-metal + HAL, STM32CubeIDE.

Полная версия на английском: [`README.md`](README.md).
Все технические разделы: [`docs/`](docs/).

## Что сделано, одной таблицей

| | Было (2021) | Стало |
|---|---|---|
| Весовой фронт-энд | Собственная плата с 5× HX711, бит-бэнг на STM32F1 | 5× индикаторов QLST на шине RS-485 Modbus RTU (адреса 1..5, 115 200 бод) |
| Весовой MCU | Отдельная плата, блокирующий `while(1)` | **Убран**: минус MCU, минус плата, минус шлейф |
| Проводка шины | Параллельный шлейф к HX711-плате | Двухпроводная RS-485, новый датчик: шлейфом |
| Калибровка | 2 кнопки + 16×2 LCD на спрятанной плате | Кнопки и экран на каждом QLST: доступно оператору |
| Связь MCU↔MCU | Исходный шлейф с HX711-платы | Собственный шилд RS-485↔UART, **встающий в тот же разъём** на плате шаговиков (плата не правилась) |
| Связь с HMI | Длинный UART-кабель к Raspberry Pi | USB CDC, один кабель, стандартный драйвер VCP |
| Структура прошивки | Всё приложение в прерывании TIM6: барабан, сопла, насосы, опрос | TIM6 ISR: только критичная моторика; Modbus: неблокирующий автомат из основного цикла, RX побайтово по IT |
| Алгоритм розлива | Bang-bang: насос ON при `g < target − 10`, OFF при `target − 1.5` | Мягкий старт → быстрый налив → подъём сопла пропорционально массе → замедление → капельный хвост → жёсткий стоп |
| Производительность | **480 бутылок/час** | **650 бутылок/час (+35 %)** |

Остальные разделы см. в основной англоязычной версии и в `docs/`.
